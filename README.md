# E-Commerce Website

A responsive, interactive e-commerce front-end built using HTML, CSS and JavaScript — designed to showcase product browsing, cart behaviour and clean UI.

## 🚀 Features  
- Responsive layout: works smoothly on desktop and mobile.  
- Product listing & filtering logic: browse products, view details.  
- Cart interactions: add/remove items, view totals (client side).  
- Clean, modern UI: built with semantic HTML and custom CSS.  
- Pure client-side implementation: no backend required, easy to adapt/integrate.

## 🧠 Why this project?  
1. Demonstrates ability to design and implement interactive web apps with vanilla JavaScript.  
2. Highlights front-end skills — HTML structure, CSS styling (responsive design), DOM manipulation.  
3. Acts as a foundation for next-step integration: hooking up with APIs, real backend, authentication, payment flows.

## 📁 Project Structure  
```text
/  
├── index.html        ← main entry point  
├── styles.css        ← site styles  
├── scripts.js        ← JavaScript logic (product data, cart, UI behaviours)  
└── assets/           ← optional assets (images, icons)  
````

*You can easily extend this with a backend, database, or framework of your choice.*

## ✅ Getting Started

To view the site locally:

1. Clone the repository

   ```bash
   git clone https://github.com/sushanthacharya2003/E-commerce-website.git
   ```
2. Navigate into the directory

   ```bash
   cd E-commerce-website
   ```
3. Open `index.html` in your browser

   ```bash
   open index.html  # or double-click the file in your file browser  
   ```
4. Start using: browse products, add to cart, test responsiveness.
